# Nutrition Programme Client Presentation

## Project Overview
This project analyses an NGO nutrition programme involving 120 beneficiaries across three counties: Nairobi, Kiambu and Machakos.

The objective is to communicate programme performance and key findings to a simulated NGO programme director through a five-slide PowerPoint presentation.

## Key Findings
- Total beneficiaries: 120
- Average weight gain: 1.95 kg
- Average programme sessions attended: 8.7
- Attendance and weight gain correlation: 0.84

## Analysis and Visualisations
The project uses Python to:
- Calculate average weight gain by county.
- Compare weight gain across age groups.
- Examine the relationship between attendance and weight gain.
- Generate three charts.
- Automatically create a five-slide PowerPoint presentation.

## Technologies Used
- Python
- Pandas
- Matplotlib
- Python-pptx

## Project Files
- `presentation.py` – Main Python analysis and presentation script.
- `nutrition_data.csv` – Programme dataset.
- `charts/` – Generated charts.
- `Nutrition_Programme_Client_Presentation.pptx` – Final presentation.

## How to Run

1. Clone or download this repository.
2. Install the required libraries:

```bash
pip install pandas matplotlib python-pptx
```

3. Run the Python script:

```bash
python presentation.py
```

4. Open `Nutrition_Programme_Client_Presentation.pptx` to view the presentation.

## Important Note
The correlation between attendance and weight gain indicates an association, not proof that attendance alone causes weight gain.
